# n8n Email Automation System

## Project Overview
This project automates email processing using n8n.

## Workflow
Gmail → IF Condition → Telegram Notification → Google Sheets

## Features
- Detects important emails
- Sends real-time Telegram alerts
- Stores data in Google Sheets

## Tools Used
- n8n
- Gmail API
- Telegram Bot API
- Google Sheets API

## Outcome
Automated email monitoring system without manual work.
